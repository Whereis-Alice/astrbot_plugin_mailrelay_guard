# 配置说明

在 AstrBot → 插件 → 我的邮件 → 配置中填写邮箱凭据与身份。邮件中心可调整非敏感开关、附件限制、记录保留和掉线通知。

## 邮箱连接

| 配置项 | 内容 |
| --- | --- |
| `smtp_host` | SMTP 服务器，163 默认 `smtp.163.com` |
| `smtp_port` | SSL 常用 `465`；STARTTLS 常用 `587`，以邮箱服务商说明为准 |
| `smtp_security` | `ssl` 或 `starttls` |
| `smtp_username` | 完整邮箱地址 |
| `smtp_password` | 邮箱网站生成的 SMTP 客户端授权码 |
| `sender_address` | 发件地址，通常与登录账号相同 |
| `sender_name` | 收件人看到的发件人名称 |
| `owner_email` | 接收主人通知的固定邮箱，也可作为掉线通知的默认收件人 |

明文 SMTP 默认被阻止。使用其他邮箱时，请按服务商提供的 SMTP 地址、端口和加密方式填写。插件页面不显示、修改或返回 SMTP 授权码。

## 谁能发给谁

| 场景 | 身份要求 | 收件人 |
| --- | --- | --- |
| 通知主人 | AstrBot 管理员，且在 `owner_sender_ids` 中 | 固定的 `owner_email` |
| 发给自己 | 当前用户能解析到邮箱或已完成邮箱验证 | 仅自己的邮箱，默认仅限私聊 |
| 发给别人 | AstrBot 管理员，且在 `admin_sender_ids` 中 | 管理员指定的邮箱 |

发送 `/邮件身份` 获取完整的 `platform_id:sender_id`，再填入对应身份列表。只在 AstrBot 中设为管理员还不够；主人和代发管理员名单分别检查。

开启 `restrict_admin_other_recipients` 后，管理员代发地址还需在 `admin_other_recipient_allowlist` 中，或匹配 `admin_other_allowed_domains`。掉线通知使用管理员预先配置的通知邮箱，独立于普通用户代发权限。

## 个人邮箱

个人邮箱来源依次为：已验证绑定、`self_email_overrides` 中的明确映射、NapCat 提供的当前用户邮箱资料。映射格式如 `aiocqhttp:123456=person@example.com`，平台部分使用 `/邮件身份` 返回的实际平台 ID。

QQ 邮箱不属于 OneBot 标准资料。`allow_qq_mailbox_derivation` 默认关闭，只有明确开启后，才会用 QQ 号拼接 QQ 邮箱；拼接不能证明用户已开通该邮箱。推荐使用验证码绑定。`/mailrelay_identity` 可查看当前邮箱来源。

## HTML 与附件

HTML 邮件默认关闭。开启 `enable_html_mail` 后重载插件，助手才能获得 HTML 邮件工具。严格清洗默认开启；链接和远程图片默认禁止。允许远程图片时，建议填写 `html_remote_image_allowed_domains`。

在当前消息中附带图片或文件，或回复含媒体的消息后要求发送。附件默认最多 6 个，单个 10 MB、合计 20 MB，读取超时 20 秒；不符合限制会拒绝整封邮件。助手生成的文件只允许来自当前会话工作区或当前事件允许的临时文件，不能读取任意服务器文件。

HTML 正文可使用 `{{image_1}}`、`{{image_2}}`，也可写 `<img src="{{image_1}}">`。插件将图片作为 CID 内嵌资源发送；未引用的图片作为普通附件。这不需要开启远程图片。

## 记录、频率和审计

`mail_history_enabled` 保存脱敏投递记录。`mail_history_store_content` 默认关闭；开启后才保存新邮件的主题与正文。附件只保存名称和大小等信息，不保存文件内容。记录根据天数和数量上限自动清理，可在邮件中心清空。

普通邮件的全局成功上限、单用户成功上限、尝试次数及发送冷却分别配置。掉线通知只在状态改变时发送；失败收件人最多额外重试 3 次，避免持续掉线时重复轰炸。

审计记录位于 AstrBot 的插件数据目录，默认启用并按文件大小轮转。不要将插件数据目录或含授权码的 AstrBot 配置上传到公开仓库。

QQ 掉线设置详见 [掉线通知](掉线通知.md)。全部配置项的说明也可直接在 AstrBot 插件配置面板中查看。
