# 开发说明

`main.py` 负责 AstrBot 生命周期、命令、模型工具和受保护的页面 API。`mailrelay_guard/` 提供配置解析、权限、SMTP、附件、HTML 清洗、历史与掉线监控。

邮件中心位于 `pages/mail-center/`，采用原生 ES 模块，无前端构建步骤或外部 CDN：

- `api.js`：AstrBot 页面桥接与独立演示数据。
- `ui.js`：通用组件、文本转义和隔离的 HTML 预览。
- `views.js`：概览、邮件、监控与设置页面。
- `offline-charts.js`：原生 SVG 掉线折线、账号时间轴与键盘 / 点选详情。
- `mail-center.js`：路由、请求状态、表单与交互。
- `mail-center.css`：响应式布局与浅色/深色外观。
- `assets/logo.svg`：原创矢量 Logo 源文件，根目录 `logo.png` 用于插件展示。

所有资源使用相对引用，页面 API 通过 `window.AstrBotPluginPage` 调用。页面未检测到桥接时明确展示演示标记；真实 API 失败不会自动切换为示例数据。

连接历史由 `mailrelay_guard/offline_history.py` 负责，使用独立 SQLite 数据库、线程异步读写与合并后的状态区间。每次采集使用同一时间戳，记录在通知邮件发送之前落地；重载、暂停、移除账号和检测间隔过长会中断连续区间，避免虚构在线率。

在插件所在目录的上一级运行：

```sh
python -m unittest discover -s astrbot_plugin_mailrelay_guard/tests -t . -v
python -m ruff check astrbot_plugin_mailrelay_guard
node --test astrbot_plugin_mailrelay_guard/tests/test_offline_charts.mjs
```

依赖 AstrBot SDK，以及 `requirements.txt` 中列出的运行库。SMTP、OneBot 和文件访问测试使用模拟对象，不发送真实邮件。

独立预览可用支持正确 JavaScript MIME 类型的 HTTP 服务打开 `pages/mail-center/`。Windows 上某些 `http.server` 环境将 `.js` 识别为 `text/plain`，需要显式设置为 `text/javascript`；AstrBot 页面服务会设置正确类型。
