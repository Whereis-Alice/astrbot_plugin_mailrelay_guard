# 常见问题

## SMTP 登录失败

检查邮箱网站是否开启 SMTP。`smtp_password` 应填写客户端授权码，不是网页登录密码；`smtp_username` 应是完整邮箱地址。发件地址通常需与登录账号一致。

## 连接超时或 TLS 错误

检查服务器、端口和加密方式是否成套填写，确认 AstrBot 所在机器能访问邮箱服务器。不要通过关闭证书验证来解决连接问题。

## 提示没有权限

发送 `/邮件身份`，将完整身份加入对应名单，并在 AstrBot 中设置同一个账号为管理员。主人通知检查 `owner_sender_ids`，管理员代发及管理命令检查 `admin_sender_ids`。测试主人邮件同时检查两种权限。

## 找不到个人邮箱

NapCat / LLOneBot 不一定提供邮箱资料。使用 `/mailrelay_bind 邮箱` 后完成验证码验证最稳妥。QQ 号拼接邮箱默认关闭，开启也不能保证用户已开通 QQ 邮箱。

## 邮件中心看不到正文

默认只记录脱敏投递结果。开启「保存主题与正文」后，只有新发出的邮件会保存内容；以前没有保存的正文无法恢复。投递副本是本地记录，不是收件方邮箱的实际收件箱。

## 有发送记录，但没有收到邮件

检查垃圾邮件箱、邮件规则、服务商发送额度及收件地址。SMTP 已接受不等于最终到达，更不等于收件人已读。记录显示“部分接受”时，可能只有部分邮箱成功提交。

## 掉线通知没有发送

检查邮件服务总开关、掉线通知开关、通知邮箱或主人邮箱。确认监控平台类型或 ID 与 AstrBot 中的连接一致，页面能显示被监控账号。达到连续失败次数后才告警。先发送测试通知，再排查 QQ 连接。

掉线期间 SMTP 同样无法连接时，重试最多 3 次；重试耗尽后请检查日志。AstrBot 或整台服务器停止后，插件也停止运行，需使用外部监控。

## HTML 或附件被拒绝

确认功能开关已开启，HTML 工具开关修改后需重载插件。检查附件数量、单个与总大小，以及禁止的文件扩展名。文件必须来自聊天消息或当前会话工作区。`{{image_1}}` 必须有对应的图片附件。

## 页面打开失败

确认 AstrBot 满足 README 中的运行要求，且通过已登录的 AstrBot 插件页面打开。刷新或重新进入插件页面以重新获取资源授权。直接打开静态页面只展示演示数据。
