# 命令用法

自然语言发送依赖 AstrBot 的模型工具调用。不能使用模型时，也可以直接执行下面的命令。

| 命令 | 用途 |
| --- | --- |
| `/mailrelay_whoami` 或 `/邮件身份` | 查看当前平台身份，填写主人或管理员白名单 |
| `/mailrelay_identity` | 查看个人邮箱及解析来源 |
| `/mailrelay_bind person@example.com` | 私聊申请邮箱绑定验证码 |
| `/mailrelay_verify 验证码` | 验证邮箱后完成绑定 |
| `/mailrelay_unbind` | 删除自己的已验证绑定 |
| `/mailrelay_self 主题 \| 正文` | 发给自己的邮箱 |
| `/mailrelay_owner 主题 \| 正文` | 通知主人；需要主人身份权限 |
| `/mailrelay_send person@example.com \| 主题 \| 正文` | 发给别人；需要代发管理员权限 |
| `/mailrelay_status` | 查看脱敏配置状态；需要管理员权限 |
| `/mailrelay_smtp_test` | 测试 SMTP 连接与登录，不发送邮件；需要配置的管理员身份 |
| `/mailrelay_send_test` | 向主人邮箱发送测试信；同时需要主人与管理员身份权限 |
| `/mailrelay_offline_test` 或 `/邮件掉线测试` | 向通知邮箱发送掉线样式测试信；需要配置的管理员身份 |

掉线测试可以在监控未开启时发送，用于先验证通知邮箱。邮件服务总开关必须开启，SMTP 必须已配置。

验证码有有效期、重发间隔和错误次数限制。绑定默认只在私聊中进行，不能替其他用户绑定邮箱。

## 助手工具

纯文本工具：`mailrelay_notify_owner`、`mailrelay_send_to_self`、`mailrelay_send_to_recipient`。

开启 HTML 邮件并重载后：`mailrelay_notify_owner_html`、`mailrelay_send_html_to_self`、`mailrelay_send_html_to_recipient`。

工具与命令共享服务端权限检查。模型提示词不能绕过收件人身份限制。附件工具参数包括 `include_message_media` 与 `attachment_paths`，由助手从消息和当前会话工作区获取文件。
