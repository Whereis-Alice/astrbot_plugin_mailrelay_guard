# 我的邮件

让 AstrBot 帮你发送邮件、图片和文件，也能在 QQ 机器人掉线时发邮件提醒你。

- **聊天发邮件**：发给自己、通知主人，或由授权管理员发给别人。
- **图片与附件**：发送聊天里的图片、文件，以及助手在当前会话中生成的报告。
- **邮件中心**：查看投递记录，阅读已保存的邮件，调整投递设置。
- **QQ 掉线守护**：支持 NapCat / LLOneBot，掉线与恢复分别通知，自带可修改的邮件模板。

## 安装

需要 AstrBot 4.27.2 或更高版本（低于 5）。在插件管理中通过仓库地址安装：

```text
https://github.com/Whereis-Alice/astrbot_plugin_mailrelay_guard
```

## 开始使用

1. 在邮箱网站开启 SMTP，并获取客户端授权码。
2. 打开「我的邮件」插件配置，填写邮箱账号、授权码、发件地址和主人邮箱。163 邮箱可以直接使用默认服务器与端口；授权码不是邮箱登录密码。
3. 私聊机器人发送 `/邮件身份`，将返回的身份填入需要的主人或管理员白名单，并在 AstrBot 中将该账号设为管理员。
4. 重载插件，执行 `/mailrelay_smtp_test` 检查连接，再执行 `/mailrelay_send_test` 给主人邮箱发送测试信。

然后就可以对助手说：

> 把这份总结发到我的邮箱。  
> 把我刚才发的图片一起附在邮件里。

个人邮箱无法自动识别时，在私聊中使用 `/mailrelay_bind 你的邮箱`，收到验证码后执行 `/mailrelay_verify 验证码`。

## 掉线通知与邮件中心

在 AstrBot 插件页面中打开「我的邮件」，进入「掉线守护」，填写通知邮箱并开启监控。默认监控 `aiocqhttp`，适用于 NapCat 和 LLOneBot；通知邮箱留空时使用主人邮箱。点击「发送测试通知」确认能收到邮件。

邮件中心展示本插件发送的本地记录，不读取邮箱服务商的收件箱。默认不保存主题和正文；需要回看内容时，可以在「投递设置」中开启保存。
